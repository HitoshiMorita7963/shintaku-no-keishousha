# キャラクターJSON仕様 v1.2

## 正規データの責務

キャラクターJSONは、キャラクター自身の基本情報とキャラクター固有ステータスを管理する。

### キャラクターJSONが持つもの

- ID
- 名前
- 組
- 年齢
- 入試No.
- 役割
- Lv1ステータス
- Lv100ステータス
- `artifact_id`
- `guardian_id`
- 加入・操作可能化に関する情報
- キャラクター固有の補足

### キャラクターJSONが持たないもの

- 神器そのものの詳細
- 守護獣そのものの詳細
- スキル本体の詳細
- 敵の詳細
- アイテムの詳細
- マップの詳細
- イベント本文

これらは各専用データを参照する。

## ステータス10項目

表示順：

`HP → SP → 攻撃 → 防御 → 素早さ → 賢さ → 技術 → 回避 → 命中 → 運`

JSONキー：

`hp, sp, atk, def, spd, int, tec, eva, acc, luk`

`stats.lv1` と `stats.lv100` は必ず同じ10キーを持つ。

## 成長

Lv2～99はLv1とLv100を直線補間する。

既存30人のLv1/Lv100値は、ユーザーから変更指示がない限り変更禁止。

## ID参照

- 神器：`artifact_id` → `ART_XXX`
- 守護獣：`guardian_id` → `GUA_XXX`

所有者情報はキャラクター側の参照を正規とする。神器JSON・守護獣JSONには `owner_id` を重複保存しない。

## A組とB組

- A組：既存の `join_episode` を加入・操作可能化の基準として使用。
- B組：最初からクラスメイトとして在籍するため `join_episode` は使用しない。
- B組の指定戦闘での操作可能話数は `playable_in_episodes` に記録する。
