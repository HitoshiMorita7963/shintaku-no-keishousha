# data/provisional — 仮仕様データ

このフォルダは **正式データではありません**。

ZIP（v1.5.1）の資料で「未確定」「null」「詳細未確定」とされている数値・ルールのうち、
Phase 1 をプレイ可能にするために **最低限必要なものだけ** を Claude が仮に定義したものです。

## 原則

- 正式データ（`data/characters` 等）は一切書き換えない。ここは「上書き」ではなく「空欄補完」。
- バリデータ（`npm run validate`）は、ここの値が正式データの **非null値を上書きしていないか** を検査する。
- 名称は正式データに存在するものだけを使う（新キャラ・新技名・新設定を作らない）。
  例外として、敵の行動名には `09_敵` / `11_イベント` に記載された名称（覇穿・地導波・大爆砕・偽獣化・拘束）のみ使用。
- すべての値はユーザー確認前の「仮採用」。`99_未確定・提案/02_Claude提案記録.md` に記録済み。
- 値の調整はこのフォルダのJSONを編集し `npm run build:data` を実行するだけでよい（コード変更不要）。

## ファイル

| ファイル | 内容 |
|---|---|
| `battle_rules.json` | ダメージ・命中・会心・行動順・属性倍率・守護獣解放などの計算パラメータ |
| `common_skills.json` | 通常攻撃・防御・神技10種（正式データでは威力/SPがnull）の仮数値 |
| `effect_rules.json` | スキルJSONの `effect` 文字列 → 戦闘処理用の構造化効果 |
| `items.json` | 回復薬・神気薬・万能薬・蘇生薬の仮効果量 |
| `enemies.json` | 敵8種の仮ステータス・行動（正式データでは `stats: null`） |
| `encounters.json` | Phase 1 テスト戦闘（訓練戦）の敵編成 |
| `progression.json` | 経験値テーブル・パーティ人数・初期所持品 |
| `ui_text.json` | UI表示用の用語ラベル |
