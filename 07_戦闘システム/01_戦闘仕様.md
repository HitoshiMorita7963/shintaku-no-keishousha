# 戦闘仕様

## コマンド
- 攻撃
- 神技
- 天撃
- 神器
- 守護獣
- アイテム
- 防御

## ステータス
HP / SP / 攻撃 / 防御 / 素早さ / 賢さ / 技術 / 回避 / 命中 / 運

## ステータス用途
HP=生命力、SP=技リソース、攻撃=物理火力、防御=被ダメージ軽減、素早さ=行動順、賢さ=天撃、技術=神技・神器系、運=会心・状態異常・追加効果・ドロップ等。

## 同族性
天撃属性が神器属性と一致すると×1.5、守護獣属性と一致すると×1.5、両方一致すると×2.25。

## 注意
具体的なダメージ計算式・耐性値など、ユーザー未確定の数値は仮仕様として扱う。
