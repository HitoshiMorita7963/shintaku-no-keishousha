## 1. プロジェクト構造

```
/                         ← ZIPの内容をそのまま配置（正式資料・無改変）
├─ README.md / CLAUDE_MASTER_PROMPT.md / project_manifest.json
├─ 00_開発ルール ～ 14_データ定義 / 99_未確定・提案   ← 仕様書（Markdown）
├─ data/                  ← 正式データ（JSON 704件・無改変）
│   ├─ characters(30) artifacts(30) guardians(30) skills(546)
│   ├─ enemies(8) items(4) maps(10) events(43) schemas(3)
│   └─ provisional/       ← ★追加：未確定値の「仮データ」（正式データとは分離）
├─ scripts/               ← 原本のPython検証スクリプト（無改変）
├─ game/                  ← ★追加：ブラウザゲーム本体
│   ├─ index.html / styles/main.css
│   ├─ generated/data.bundle.js   （data/ から自動生成）
│   └─ src/
│       ├─ core/    定数・乱数・汎用関数
│       ├─ data/    GameData（正規化・参照解決）・validate（整合性チェック）
│       ├─ model/   成長計算（キャラLv/神器Lv/親和度）・ゲーム状態
│       ├─ battle/  戦闘エンジン（UI非依存）・計算式・コマンド・敵AI
│       └─ ui/      画面（タイトル/選択/学園/戦闘/結果/ステータス/検証/開発者設定）
├─ tools/                 ← ★追加：検証・ビルド・開発サーバー・原本ロック
├─ tests/                 ← ★追加：自動テスト（35件）
└─ docs/                  ← ★追加：本レポート
```

## 2. 使用技術

| 項目 | 採用 | 理由 |
|---|---|---|
| 言語 | JavaScript（ES Modules）＋ JSDoc 型注釈 | 資料でエンジン未確定。ブラウザでそのまま動き、ビルド不要 |
| 型安全 | TypeScript コンパイラで `checkJs`（strict）検査 | `npm run typecheck`。実行時はTS不要 |
| 画面 | HTML / CSS（フレームワークなし） | スマホ・PC両対応、依存ゼロ |
| データ | data/*.json → `game/generated/data.bundle.js` | JSON編集→`npm run build:data`でゲームに反映（コード変更不要） |
| テスト | Node 標準 `node:test` | 依存なし |
| 検証 | `tools/validate.mjs`（Node） | この環境に Python が無いため、原本 `scripts/*.py` と同等以上の検査を Node で実装 |

## 7. 最初に実装する範囲（Phase 1）＝ 実装済み

タイトル／ニューゲーム／キャラクター選択（A組15人）／A組データ読み込み／戦闘開始／攻撃・神技・天撃・神器・守護獣・アイテム・防御／敵AI／ターン制（素早さ順）／勝敗判定／経験値／Lvアップ／SP管理。加えて：ステータス画面、パーティ編成、休息、開発者設定（Lv・神器Lv・親和度・上位属性覚醒を直接設定）、ゲーム内データ検証画面。

### 仮採用した値（`data/provisional/` に分離・正式データは無改変）

| 項目 | 仮仕様 |
|---|---|
| ダメージ式 | 威力 × 攻撃値² ÷ (攻撃値 + 防御) × 1.5 × 乱数0.9–1.1（比率型：Lv1～100で破綻しにくい） |
| 参照ステータス | 物理=攻撃、天撃=賢さ、混合=攻撃と賢さ半々、神技=攻撃0.7＋技術0.3 |
| 命中 | 0.95 ＋ (命中−回避)/(命中＋回避)×0.5、40%～99%に制限。天撃は必中 |
| 会心 | 3% ＋ 8%×運比 ＋ 神器節目補正、上限50%、×1.5 |
| 同族性 | **資料どおり**（×1.5／×1.5／×2.25、天撃のみ）。上位属性は基本属性一致でも同族扱い（仮） |
| 守護獣解放 | 最大SPの15%（最低5）を消費、戦闘終了まで持続、1戦闘1回。倍率は「キャラ基礎値」に掛け、神器補正は後から加算 |
| 天撃の使用可否 | ✅**ユーザー確認済み**：全キャラが全属性の基本天撃を使用可。神器・守護獣と属性不一致なら同族性補正なし。**染川咲のみ天撃全属性マスター・属性不一致の天撃ダメージ×1.2**（一致時は同族性のみ）（`data/confirmed/character_traits.json`）。上位属性はシナリオ台本に従う（受領待ち。それまで覚醒フラグ制・自分の属性に対応するもののみ） |
| 神技10種 | 名前から効果を仮解釈（剛撃＝強打、連舞＝2回攻撃、崩撃＝防御低下 等）。画面に「仮」表示 |
| 敵 | 8種に lv1/lv100 の仮ステータス。行動は汎用名のみ |
| アイテム | 回復薬=HP30%、神気薬=SP30%、万能薬=状態異常回復、蘇生薬=HP25%で復活 |
| 経験値 | 次Lvまで round(10 × Lv^1.6)。Lv上昇時の能力値は正式Lv表 |
| パーティ | 最大4人（第21話「5対5」から5人の可能性あり） |
